- **[2026-06-20] [B266]**: A Safari/iOS "Load failed" (a `fetch()` TypeError, not an HTTP status) on a write usually means the request got **no CORS-valid response** — most often a backend **500 whose error response lacks CORS headers**, so the browser masks the real status.
