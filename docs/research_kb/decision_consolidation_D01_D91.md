## 1. CONFLICTS & TENSIONS (require resolution)

### T1: D21 (min phase duration) vs D44 (ARC min 6 weeks)
- **D21:** Set minimum phase duration constraint (from Topic 04, general principle)
- **D44:** ARC/endurance phase specifically needs ≥6 weeks (Mujika 2012: mitochondrial biogenesis timeline)
- **Tension:** D21 was left as a general constraint without a specific number. D44 now gives a hard floor for the Base/ARC phase.
- **Resolution:** D44 overrides D21 for endurance/ARC phases. Other phases (Build, Peak) can have shorter minimums. **D21 should be updated: Base/ARC phase min = 6 weeks; Build phase min = 3 weeks; Peak/Realisation min = 2 weeks.**

### T2: D19 (beginner simple linear) vs D27 (reverse periodization for beginners)
- **D19:** Simplified linear periodization for beginners (from Topic 04)
- **D27:** Evaluate reverse periodization for beginners (House & Johnston 2014, from Consuegra Ch.10)
- **Tension:** Two competing models for beginners. Which one?
- **Resolution:** DEFER — both are valid. D19 is the safer v1 default (well-understood, low injury risk). D27 remains on research watchlist. The Consuegra Ch.8 data (D51: beginners should spend 70% climbing) actually supports D19 — beginners need volume and climbing time, not intensity-first approaches. **Keep D19 for v1. D27 remains v2 research item.**

### T3: D16 (audit 4×4 parameters) vs D47 (replace 4×4 entirely)
- **D16:** Audit 4×4 session parameters (from Topic 03 — adjust rest times, intensity)
- **D47:** Replace traditional 4×4 with Consuegra's varied-intensity interval method
- **Tension:** D16 assumes we keep 4×4 and tweak it. D47 says scrap it.
- **Resolution:** D47 supersedes D16. The Consuegra/Valenzuela evidence is strong — 4×4 drives total vascular occlusion which is counterproductive. The varied-intensity interval method is a better design. **D16 → SUPERSEDED by D47.**

### T4: D15 (progressive ARC duration) vs D44 (ARC min 6 weeks) + D45 (<25% MVC ceiling)
- **D15:** Progressive ARC duration in Base phase (from Topic 03)
- **D44/D45:** 6-week minimum + <25% MVC intensity ceiling
- **Tension:** No real conflict, but D15 was vague on specifics. D44 and D45 now give hard parameters.
- **Resolution:** D15 is CONFIRMED and EXTENDED by D44+D45. Progressive ARC means: start at beginner volume (8-12 min per López-Rivera 2014c), build toward advanced volume (40+ min), over a minimum of 6 weeks, always staying below 25% MVC / 1-2 on pump scale. **D15 updated with D44+D45 constraints.**

### T5: D14 (López load monitoring) vs D34 (Effort Level) + D52 (EL/%1RM by level)
- **D14:** López load monitoring rule for adaptation system (from Topic 02)
- **D34:** Integrate Effort Level as primary intensity metric
- **D52:** EL/%1RM prescription table by level
- **Tension:** D14 was about monitoring training response. D34 and D52 are about prescribing intensity. These are complementary but need to use the same language.
- **Resolution:** All three are COMPATIBLE. D14 monitors load via the same EL metric that D34/D52 prescribe. **Unify under a single "EL-based intensity system" — D34 defines it, D52 sets ranges by level, D14 monitors response.**

### T6 (NEW): D73 (technique drills 30%+ for beginners) vs D51 (climbing:conditioning ratio by level)
- **D73:** Beginners should spend 30%+ of session time on technique drills
- **D51:** Beginners should spend 70% climbing, 30% conditioning
- **Tension:** Does technique drill time come from the "climbing" bucket or the "conditioning" bucket?
- **Resolution:** Technique drills ARE climbing (on-wall drills like silent feet, downclimbing, freeze). The 30%+ technique drill time comes from WITHIN the 70% climbing portion. So a beginner session = 70% climbing (of which ≥30% = technique drills, rest = climbing for grade/volume) + 30% conditioning. **No real conflict — just clarify that technique drills ⊂ climbing time.**

### T7 (NEW): D75 (structured route preview) vs D28 (route preview prompt)
- **D75:** Structured route preview protocol with checklist (identify rests → plan crux → visualise clipping → plan descent)
- **D28:** Simple route preview prompt in guided session mode
- **Tension:** D75 is a full upgrade of D28.
- **Resolution:** D75 UPGRADES D28. D28 was a simple prompt; D75 provides structured protocol. **D28 is absorbed into D75.** The route preview is now a multi-step guided process, not just a reminder.
