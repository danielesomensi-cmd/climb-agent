# Loading Pin — Analysis & Literature Review

## Summary
The loading pin (arm-lifting / block pulls) is an alternative to hangboard training.
It isolates finger strength without shoulder loading, is naturally unilateral,
and uses the same protocols (MaxHangs, Repeaters, Density Hangs) transposed to lifts.

## Key facts from literature
- Load model: external_load (never add bodyweight to the load)
- Conversion: LP_per_hand ≈ (HB_total_load / 2) × 0.90
- Reverse: HB_total ≈ (LP_stronger_hand × 2) / 0.90
- Duration conversion (Rohmert curve approx): 5s→7s ×0.93, 5s→10s ×0.85
- Training zone: 70-90% of 1RM for strength (Bompa flat pyramid)
- Always one hand at a time, separate maxes for L and R
